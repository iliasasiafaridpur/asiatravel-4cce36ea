হ্যান্ডওভার পাসপোর্ট প্রদর্শন সংশোধন — Vercel আপডেট

এটি আপনার আগের প্রজেক্টের জন্য ছোট আপডেট ZIP, নতুন সম্পূর্ণ অ্যাপ নয়।

১. ZIP Extract করুন।
২. GitHub Desktop-এ আপনার চলমান Vercel প্রজেক্টের Repository → Show in Explorer খুলুন।
৩. ZIP-এর src ফোল্ডারটি প্রজেক্টের মূল ফোল্ডারে কপি করুন। একই নামের ফাইল Replace করুন।
   পুরনো src ফোল্ডার ডিলিট করবেন না; অন্য ফাইল, .env, package.json বা Vercel settings পরিবর্তন করবেন না।
৪. GitHub Desktop-এ পরিবর্তন দেখে Commit to current branch → Push origin দিন।
৫. Vercel-এর deployment Ready হলে পেজ Refresh করে হ্যান্ডওভারের স্ক্রিন ও প্রিন্ট দেখুন।

সংশোধন:
- মূল বুকিংয়ের সংরক্ষিত পাসপোর্ট এজেন্সি ও অতিরিক্ত সার্ভিসের সংযুক্ত রসিদেও পড়া হয়।
- ভেন্ডরের নাম না থাকলেও পাসপোর্ট পাওয়া যায়।
- স্টাফ হ্যান্ডওভারে অতিরিক্ত সার্ভিসের তথ্য যুক্ত হয়েছে।
- সিঙ্গেল ও একাধিক মাধ্যমে গ্রহণ করা রসিদের প্রিন্টে কাস্টমার কলামে পাসপোর্ট যুক্ত হয়েছে।
- মূল বুকিং পাওয়া না গেলে সংযুক্ত রেকর্ডে থাকা পাসপোর্ট ব্যবহার হয়।
- পাসপোর্ট কোথাও সংরক্ষিত না থাকলে বানিয়ে দেখানো হয় না।
- মোটের উপর এজেন্সির সম্মিলিত সারি আগের মতোই থাকবে; একাধিক যাত্রীর জন্য একটি পাসপোর্ট দেখানো হয় না।

টাকার হিসাব, পেমেন্ট, হ্যান্ডওভার গ্রহণ/বাতিল বা ডাটাবেস পরিবর্তন করা হয়নি। কোনো SQL চালাতে হবে না।
